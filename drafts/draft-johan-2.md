# DRAFT-Johan-1: Self-Censored Content

The network should not prohibit adult content. In a free world you can share what you want to share. Of course — as proposed by [DRAFT-Johan-0](./draft-johan-0.md) — the nodes can decide not to partake in the spread.

To help in this effort, the sender of an atom can (and maybe should) include a tag that marks the atom as sensitive. A device used by a child can then be configured to avoid displaying such content.

Similar tags can be added to depictions of violence and other content. If a user broadcasts such content without labelling it, they might be banned or blocked by grid node moderators.
