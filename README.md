# This is Siân

The IETF defines the internet through  [RFCs](https://en.wikipedia.org/wiki/Request_for_Comments) and [BCPs](https://en.wikipedia.org/wiki/Best_Current_Practice) documented through the [RFC Editor](https://www.rfc-editor.org/).

This project documents RFCs for a federated network named SIAN, an acronym for a Federated Interest-driven and Avatar-based Social Network — or “Social Interest and Activity Network” if you prefer reading out the initials in order. Start with [RFC-0](./rfc-0.md) for an introduction to the idea or check out [RFC-1](./rfc-1.md) for the source of the name.

- [RFC-0](./rfc-0.md): Federated Interest-driven, Avatar-based Social Network
- [RFC-1](./rfc-1.md): Siân
- [RFC-2](./rfc-2.md): Process for Additions and Amendments
