# RFC-1: Siân

**Status:** N/A
**Category:** Informational
**Author**: Johan Segerfeldt
**Date Published**: Sep 2 2026

[RFC-0](./rfc-0.md) proposes a “Federated Interest-driven, Avatar-based Social Network.” The initials — slightly scrambled — spell out the acronym F-SIAN, which matches the spelling of the Welch name [Siân](https://en.wikipedia.org/wiki/Siân). That is the proposed name for the system.

The name came about serendipitously from [RFC-0](./rfc-0).

> I used expressions like “Federated Interest-driven, Avatar-based Social Network” and “Federated Social Interest and Activity Network.” I realised that he initials spell out the Welsh name Siân, so I have published my initial ideas under that name.
> — Johan

> And yes: _"the project accidentally named itself Siân"_ is now officially part of the story. 😄
> — Chat GPT

Since github.com /sian was already taken, the proposed community name is SIÂN Federation, based from the GitHub organization <https://github.com/sianfederation>

If we define a new internet protocol, we could use `sian:` as its protocol id in URIs. See Claude’s [RFC-5](./drafts/draft-claude.ai-5.md) for a detailed draft.
