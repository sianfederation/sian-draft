# RFC-1: Siân

**Author**: Johan Segerfeldt
**Date Published**: Sep 2 2026

[RFC-0](./rfc-0.md) proposes a “Federated Interest-driven, Avatar-based Social Network.” The landing page of this site uses the expression “Federated Social Interest and Activity Network.” The same letters, but in a slightly different order.

The initials spell out the acronym F-SIAN, which matches the spelling of the Welch name [Siân](https://en.wikipedia.org/wiki/Siân). That is the proposed name for the system.

Since github.com /sian is already taken, the community has claimed the organization name <https://github.com/sianfederation>

If we define a new internet protocol, we could use `sian:` as protocol id in URIs.
