# RFC-1: Siân

[RFC-0](./rfc-0.md) proposes a “Federated Interest-driven, Avatar-based Social Network,” or FIASN. A slight rearranging of the initials spells the Welch name [Siân](https://en.wikipedia.org/wiki/Siân) (sometimes spelled Sian or Shan).

If we define a new internet protocol, we could use `sian:` in URIs.
